# PDF Merger
===============

## 📌 Project Overview
--------------------------

PDF Merger is a Python-based application that allows users to combine multiple PDF files into a single PDF document. It simplifies document management by providing a convenient and efficient way to merge PDF files.

## ✨ Features
---------------

- Merge multiple PDF files into one document.
- Simplifies PDF document management.
- Helps organize multiple PDF files into a single document.
- Built using Python.

## 🛠️ Technologies Used
------------------------

- **Programming Language:** Python
- **Library:** pypdf
- **GUI:** Tkinter (if used in the project)

## ⚙️ Installation and Setup
-----------------------------

### 1. Clone the Repository

```bash
git clone https://github.com/KavyaSriKatta/PDF-Merger.git
```

### 2. Navigate to the Project Directory

```bash
cd PDF-Merger
```

### 3. Install the Required Library

```bash
python -m pip install pypdf
```

### 4. Run the Project

```bash
python PDF_Merger.py
```

## 🚀 How It Works
------------------

1. Select the PDF files you want to merge.
2. Arrange the files in the required order, if supported.
3. Choose the destination for the merged PDF.
4. Run the merge operation to generate a single PDF document.

## 🎯 Project Objective
-------------------------

The main objective of this project is to simplify PDF document management by combining multiple PDF files into one organized document using Python.
